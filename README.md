## agenda-contatos

Aplicação em Python desenvolvida para cadastrar, listar, buscar e remover contatos pelo terminal.

## Funcionalidades

- Cadastrar um novo contato com nome, telefone e email
- Listar todos os contatos cadastrados
- Buscar um contato pelo nome
- Remover um contato

## Como executar

```bash
python agenda.py
```
